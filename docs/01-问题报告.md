# 问题报告：长任务的状态与恢复缺失（基线版）

- **严重度**：P0（流水线任意一步失败即人工从头排查；外发/上传重放直接损伤客户关系与商店后台）
- **报告日期**：2026-10-13
- **状态**：未修复（本目录为基线 v0.1.0）

## 现象

`生成配置 → 渲染预览 → 截图发客户 → 等客户确认（数小时~数天）→ Android 打包 → iOS 签名 → 提审材料 → 上传商店` 全链由对话式 Agent 顺序驱动：

- 进度只有一份非结构化 `memory.txt`；任意一步崩溃/超时/会话过期后只能从头重跑；
- 重跑 = 重放全部副作用：客户收到两条一样的消息、商店后台重复版本；
- 签名/上传/外发无审批门；并发写后写覆盖；无看门狗无审计。

## 失败场景

S1 中途崩溃；S2 等待期会话蒸发；S3 副作用重放；S4 高危动作重放；S5 并发覆盖；S6 半完成不可见；S7 memory 当状态存储。逐条对位与复现见修复仓库 `docs/01~02`。
