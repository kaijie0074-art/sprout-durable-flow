## 单点复现（不走测试）

```bash
T=$(mktemp -d)
# 1) 跑到 ios_sign 注入 SIGKILL
python3 -m durable_flow.cli --base-dir "$T" run --task t1 --crash-at ios_sign
# 2) "恢复"= 从头重跑（现状唯一选项）
python3 -m durable_flow.cli --base-dir "$T" run --task t1
# 3) 数一数客户收到了几条消息、商店被传了几次
grep -c send_message "$T/logs/journal.jsonl"   # → 2（客户收到两条一模一样的截图消息）
grep -c '"upload"' "$T/logs/journal.jsonl"     # → 2（商店后台重复版本）
cat "$T/memory.txt"                            # → "全部完成"——进度=一行文本，崩溃历史无处可查
```

## 结论

基线把"执行"寄生在会话里：无检查点、无幂等、无门、无狗、无审计。修复后对照见 [06-回归记录.md](06-回归记录.md)。
